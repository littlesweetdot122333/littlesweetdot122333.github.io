# 安居

COFFEEE 制作的独立恐怖互动项目。博客介绍使用猫咪作者第一视角；作品内是虚构公司的产品界面、设备记录与客服对话。

纯静态 HTML / CSS / JavaScript，不使用外部服务、真实摄像头或麦克风。故事状态仅存入当前标签页会话的 sessionStorage，失败时降级为内存状态。页面底部“重新体验”可恢复初始状态。

游玩顺序：演示住宅 → 昨夜报告 → 小型活动过滤 → 卧室隐私设置 → 走廊留存画面对比 → 三次客服问答 → 夜间照明设置 → 服务总结 → 返回演示住宅。返回后约 4 秒与 9 秒出现后续记录；未关闭照明也可以完成故事，走廊画面按当前设置显示。

`state.mjs` 是可独立测试的状态模型；`app.mjs` 负责 DOM、交互、记录恢复和时序。使用同目录的相对资源路径。构建器将此目录复制到 `dist/projects/anju/`，博客的 `/projects/` 列出入口。
