# Little Sweet Blog

这是一个零构建依赖的静态个人博客，可以直接部署到 GitHub Pages。

## 文件说明

- `index.html`: 首页
- `styles.css`: 样式
- `posts/`: 文章页面
- `assets/hero.jpg`: 首页封面图
- `.nojekyll`: 让 GitHub Pages 按普通静态文件发布

## 免费部署目标

GitHub Pages 仓库名：

```text
littlesweetdot122333.github.io
```

部署后地址：

```text
https://littlesweetdot122333.github.io
```

## 修改文章

新增文章时，在 `posts/` 下新建一个 `.html` 文件，然后在 `index.html` 的文章列表里添加链接。
